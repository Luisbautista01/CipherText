GUÍA SIN CONEXIÓN

¿Qué hace el cifrado?

  1. Tu mensaje o archivo se convierte en datos protegidos.
  2. AES-GCM cifra y verifica que no se haya alterado el contenido.
  3. Solo con la contraseña correcta puedes recuperar el contenido original.

Cifrado con AES-256-GCM (Advanced Encryption Standard); las claves se derivan de forma segura mediante Scrypt.

INFORMACIÓN

            
Preguntas frecuentes

          

        

        

          

            ¿Qué algoritmo se utiliza?
            
AES-256-GCM con claves derivadas mediante Scrypt.

          

          

            ¿Qué tan segura es la encriptación?
            
Detecta contraseñas incorrectas y modificaciones del contenido cifrado. Usa una contraseña segura y
              única.

          

          

            ¿Cómo comparto la contraseña de forma segura?
            
Compártela por un canal distinto al que usaste para enviar el archivo cifrado.

          

          

            ¿Mis datos se guardan?
            
El historial conserva el contenido cifrado. Las contraseñas de cifrado no se guardan.
